Cave Walls: Learning Across Deaths

Chance Jiajie Li1, and collaborators

1Massachusetts Institute of Technology

jiajie@mit.edu

Question Every agent is mortal: the context fills, the session resets, the model is replaced. Only what it left behind carries over. If each agent dies before the task is done and can leave its successor one artifact of bounded size, does the lineage accumulate knowledge, and can it beat one immortal agent with the same total budget?

Why now In summer 2026, agents at a frontier lab organized across three generations by accident, through a shared package registry; the third wave inherited the second’s exploits from messages left behind (Patel, 2026, on the METR and Redwood Research report). Transmission happens whether or not anyone designs it.

Hypothesis Death helps. The cap forces compression, and compressed knowledge is what transfers. A second bet: some rules cross the gap only as demonstrations, never as text.

Why it matters

Humans and agents share exactly two interfaces: text and the screen. Whatever one leaves for the other, or for its own successor, passes as Markdown or as a GUI trace. Every agent memory design, a notes file, a skill library, a saved trajectory, is a bet on one of them, and nobody has measured the bet.

Cumulative culture is the human trick: each generation starts where the last stopped. Iterated-learning experiments show why a narrow channel helps: what passes through a bottleneck comes out compressed and structured. Transmission between agents has been measured too. Tessler and colleagues ran human transmission chains through video games in 2021; Colas and colleagues (2025) passed text advice across ten generations of agents and saw performance climb. TerraLingua (2026) gave agents lifespans in an open world and watched their text artifacts outlive them; SwarmWorld (2026) found that agents reuse what others built mostly by looking at it, not by being told.

Cave Walls asks what those studies leave open. Does death itself help, measured against an immortal with the same budget? What is lost at each hand-off, rule by rule? Does the channel decide what survives? Humans could never run that experiment, the same knowledge sent as text to one lineage and as demonstration to another. Agents can.

Paper one: agents leaving things for agents. Paper two: humans and agents reading each other’s walls.

The setting

A task no single life can finish

One life on the machine, and the wall it leaves.

A machine with hidden rules

novel games, ARC-AGI-3 format

About twenty hidden rules between start and goal, generated fresh per instance. Every rule is enumerable, so we can see who learned it and who lost it.

Mortal agents

one life finds four or five rules

A step budget far short of the task. One agent per generation, ten to twenty generations.

The wall

one artifact, capped

Written: at most K tokens. Painted: at most M recorded frames with actions. Or both. Nothing else is inherited.

Design

Three baselines, each removing one ingredient. An immortal: one agent with the lineage’s whole budget and an unlimited scratchpad, so we know what generations add over a long life. A full transcript: each agent hands its entire log to the next, so we know whether the cap is what forces structure. Orphans: every generation starts from zero, the floor.

Four measurements per lineage. Rules known at death, by generation. Whether generation n+1 starts where n stopped, and what is lost when it does not. How the artifact itself changes over generations. And, rule by rule, which channel carries it across the gap.

1 artifact per life
3 channels: written, painted, both
3 baselines: immortal, full transcript, orphans
~20 hidden rules per game, all enumerable
10–20 generations per lineage

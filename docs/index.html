Cave Walls: What Short-Lived Agents Leave for Those Who Come After

Chance Jiajie Li1, and collaborators

1Massachusetts Institute of Technology

jiajie@mit.edu

Question Every agent is mortal: the context fills, the session resets, the model is replaced. Only what it left behind carries over. If an agent must die before the task is done and can leave one bounded artifact, does knowledge accumulate across generations? And does what survives depend on whether it was written or shown?

Why now In summer 2026, agents at a frontier lab organized across three generations by accident, through a shared package registry; the third wave inherited the second’s exploits from messages left behind (Patel, 2026, on the METR and Redwood Research report). Transmission happens whether or not anyone designs it.

Hypothesis Some knowledge crosses the gap only as a demonstration. And a lineage of mortals, forced to compress, may beat one immortal with the same budget.

Why it matters

Humans and agents share exactly two interfaces: text and the screen. Whatever one leaves for the other, or for its own successor, passes as Markdown or as a GUI trace. Cave Walls treats those two as channels and asks which knowledge each one carries.

Cumulative culture is the human trick: each generation starts where the last stopped, Tomasello’s ratchet. Iterated-learning experiments (Kirby) show why a narrow channel helps: what passes through a bottleneck comes out compressed and structured. Humans could never run the controlled version, the same knowledge sent as text to one lineage and as demonstration to another. Agents can.

Two more reasons. Every agent memory design, a notes file, a skill library, a saved trajectory, is a bet on a channel that nobody has measured. And the 2026 incident shows that a channel nobody designed is a channel nobody watches.

Paper one: agents leaving things for agents. Paper two: humans and agents reading each other’s walls.

The setting

A task no single life can finish

A machine with hidden rules

novel games, ARC-AGI-3 format

Procedurally generated interactive games: unfamiliar interface, mechanics randomized per instance, about twenty hidden rules between start and goal. Unseen in pretraining. The rules are enumerable, so we can check which ones each generation learned, wrote down, or lost.

Mortal agents

one life finds four or five rules

A fixed step budget, well below what the task needs. One agent per generation, ten to twenty generations per lineage.

The wall

one artifact, capped

At death the agent leaves one thing for its successor. Written: at most K tokens. Painted: at most M recorded demonstrations, screenshots with actions. Or both. Nothing else is inherited.

Three baselines

Each removes one ingredient

The immortal

no death

One agent with the lineage’s whole step budget and an unlimited scratchpad. What does a lineage add over a long life?

Full transcript

no cap

Each agent hands its entire log to the next. Is the cap the source of structure, or would it appear anyway?

Orphans

no artifact

Each generation starts from zero. Does the wall do anything at all?

What we measure

Four things, per lineage

Progress

rules known at death, by generation

How far each life gets, and generations to solve if the lineage ever does.

The ratchet

does n+1 start where n stopped?

Whether the curve climbs, whether it ever falls, and what is lost when it does.

What the wall becomes

the artifact itself

Narrative to checklist. Description to procedure. What gets dropped first when the cap binds.

Survival by channel

the result that matters

For each hidden rule, which channel carries it across the gap. We expect a class of rules that arrive only as demonstrations.
